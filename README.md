 
# 🐾 Patinhas do Bem

### Resgatando vidas, espalhando amor!

O **Patinhas do Bem** é um projeto acadêmico de desenvolvimento web que tem como objetivo apresentar uma ONG fictícia voltada à proteção animal, promovendo a adoção responsável, o acolhimento de animais e a participação de voluntários.

O site foi desenvolvido para oferecer uma experiência simples, organizada e intuitiva, permitindo que os visitantes conheçam a iniciativa, visualizem animais disponíveis para adoção e tenham acesso às opções de participação e contribuição.

---

## 🌿 Sobre o projeto

A proposta do Patinhas do Bem é utilizar a tecnologia como ferramenta de apoio à causa animal, criando uma plataforma que reúne informações sobre a ONG e suas atividades.

O projeto busca transmitir acolhimento, responsabilidade e conscientização sobre a importância da proteção animal.

## ✨ Funcionalidades

- **Página inicial:** apresentação da ONG, sua proposta, serviços e integrantes do grupo responsável pelo projeto.
- **Nossos pets:** exibição de animais disponíveis para adoção, com fotos e informações como nome, idade e porte.
- **Cadastro de pets:** formulário para cadastrar animais, informar suas características e adicionar fotos.
- **Seja voluntário:** formulário para pessoas interessadas em fazer parte da iniciativa.
- **Doações via Pix:** área destinada às contribuições financeiras, com seleção de valor e cópia da chave Pix.
- **Solicitação de resgate:** formulário para informar situações de animais abandonados, feridos ou em risco.

## 💻 Tecnologias utilizadas

- **HTML5:** estruturação das páginas e organização dos conteúdos.
- **CSS3:** estilização, identidade visual, layout e responsividade.
- **JavaScript:** interatividade, navegação entre páginas, pré-visualização de imagens, validação e mensagens de confirmação dos formulários.

## 🎨 Identidade visual

O site utiliza uma identidade visual baseada em tons de verde e branco, transmitindo uma sensação de acolhimento, tranquilidade e cuidado.

A interface foi pensada para facilitar a navegação e manter uma apresentação visual consistente entre as páginas.

## 📚 Objetivo acadêmico

Este projeto foi desenvolvido como parte das atividades acadêmicas do curso de Análise e Desenvolvimento de Sistemas, com o objetivo de aplicar conhecimentos de desenvolvimento web, organização de arquivos, estruturação de páginas e programação com JavaScript.

Durante o desenvolvimento, foram trabalhados conceitos de HTML, CSS, JavaScript, navegação entre páginas e criação de interfaces interativas.
